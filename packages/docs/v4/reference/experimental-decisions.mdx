<Warning>
  Experimental. The surface, its configuration, and its behavior may change between releases.
</Warning>

Configure `experimentalDecisions`, then call its `act()`, `observe()` or `extract()` methods. Stagehand builds
bounded choices from page evidence, asks the decision model to select, and uses the configured LLM
when the request cannot be resolved safely. The methods accept the same arguments and return the
same result shapes as their ordinary counterparts.

`act()` selects complete click or literal-fill actions and checks the target before input. Other
operations use the ordinary LLM pipeline. `extract()` maps schema fields to page records and copies
values, with schema and evidence checks. `observe()` selects one target or classifies every candidate in a matching set, with
explicit abstention and a fresh evidence check. Without an instruction it enumerates interactive
controls without model inference. You do not select an action or extraction policy.

The ordinary methods on the Stagehand instance never call the decision provider. A namespace call
without configuration fails. LLM fallback needs an ordinary model configuration or the existing
Browserbase gateway; a decision-provider API key does not provide LLM credentials.

## Providers

| `provider` | Default model | Required connection settings |
| --- | --- | --- |
| `"perplexity"`, the default | `pplx-decider-v1.3` | `apiKey` |
| `"typesafe"` | `jev-1.14.0` | `apiKey` |
| `"cloudflare"` | `clef` | `apiKey` and `accountId`, or an account-scoped `apiUrl` |

An explicit `model` applies to both action and extraction requests. Perplexity also supports
`pplx-decider-flash-v1.3`. Providers have different coverage and confidence calibration. The default
policy is led by Perplexity's live-page comparisons; these results do not guarantee performance on
all pages or equivalent native coverage from other providers. Only Perplexity currently supplies
the bounded Locate second reading used by scalar extraction.

Candidate descriptions and page context are sent to the provider for actions. Declared variable
values of at least three characters are redacted in action requests, including values visible from
earlier actions. Shorter values remain visible. Extraction sends relevant page text and field
instructions to the provider. Avoid placing sensitive literals in instructions; use variables for
actions that need them.

## Configuration

Pass `experimentalDecisions` when creating Stagehand. Python uses `experimental_decisions` and
snake_case keys. An omitted provider selects Perplexity. Earlier prototype policy flags are removed
and rejected by configuration validation.

| Field | Default | Meaning |
| --- | --- | --- |
| `provider` | `"perplexity"` | `"perplexity"`, `"typesafe"`, or `"cloudflare"`. |
| `apiKey` | required | The decision provider's API key. |
| `model` | provider default | A supported decision model used for all three operations. |
| `apiUrl` | provider endpoint | An HTTPS endpoint override, without query or fragment. |
| `accountId` | none | Cloudflare account ID, required unless `apiUrl` supplies the account-scoped endpoint. |

## Quick start

```typescript
const stagehand = await Stagehand.create({
  browser,
  model: "openai/gpt-5.4-mini",
  experimentalDecisions: { apiKey: process.env.PERPLEXITY_API_KEY!, model: "pplx-decider-v1.3" },
});

await stagehand.experimentalDecisions.act("Click the sign in button");
const actions = await stagehand.experimentalDecisions.observe("Find the search field");
const product = await stagehand.experimentalDecisions.extract("Extract the product", ProductSchema);
```
