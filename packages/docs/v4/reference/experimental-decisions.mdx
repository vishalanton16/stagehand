</Warning>

A decision model answers small typed questions ("which of these options", "yes or no") with
probabilities. It does not generate text, and it answers in a few hundred milliseconds. The
`experimentalDecisions` namespace runs `act()`, `observe()`, and `extract()` through such questions
and hands over to the ordinary LLM pipeline whenever the model is not confident, so results have the
same shape as the regular methods and are usually faster.

The namespace is opt-in twice: configure a provider when you create Stagehand, then call the methods
on the namespace. `act()`, `observe()`, and `extract()` on the Stagehand instance itself never use
the decision model. Calling a namespace method without the configuration fails with an error.

## Providers

| `provider` | Model (default) | Needs |
| --- | --- | --- |
| `"typesafe"` (default) | TypeSafe Jev (`jev-latest`) | `apiKey` |
| `"cloudflare"` | Cloudflare Clef (`clef`, or `clef-flash`) | `apiKey`, `accountId` |
| `"perplexity"` | Perplexity Decider (`pplx-decider-latest`) | `apiKey` |

Acceptance thresholds were tuned on TypeSafe Jev. Other providers answer the same questions through
the same validation, but their probabilities are not calibrated identically; measure on your own
pages before relying on them.

The instruction, descriptions of candidate elements built from the accessibility tree, and the page
URL without query string or fragment are sent to the provider. `extract()` also sends page or
extracted content. Values of `%variables%` are replaced by their placeholders.

## Configuration

Pass these as `experimentalDecisions` when creating Stagehand. Python uses `experimental_decisions` with snake_case keys (`api_key`, `account_id`, `target_readiness`, ...).

| Field | Default | Meaning |
| --- | --- | --- |
| `provider` | `"typesafe"` | `"typesafe"`, `"cloudflare"` or `"perplexity"`. |
| `apiKey` | required | The provider's API key. |
| `model` | provider default | The provider's model name. |
| `apiUrl` | provider default | An `https` endpoint that replaces the provider's default one. |
| `accountId` | none | The Cloudflare account id. Required for `"cloudflare"`. |
| `actConfidence` | `0.7` | Minimum confidence, from 0 to 1, to act on an answer. |
| `llmFallback` | `true` | Hand over to the LLM pipeline when the decision model is not confident. With `false` the call fails instead. |
| `argumentLlm` | `true` | Allow a small LLM call that lifts unquoted text to type from the instruction. |
| `extract` | `"pick"` | `"pick"` picks the elements holding each value and copies their text. `"judge"` keeps the LLM extraction and replaces only its completion check. `"native"` uses Clairic structured extraction for Cloudflare or Decider Locate for Perplexity. |
| `targetReadiness` | `false` | Act as soon as the target is found and stable instead of waiting out the DOM-settle window. |
| `tools` | `false` | Let `act()` invoke a WebMCP tool the page registered when the decision model is sure the tool is the request. |
| `cacheCheck` | `false` | Ask the decision model whether a cached action's selector still points at a matching element before replaying it. |
| `pageState` | `true` | Check for captchas, access-denied pages, and similar states when no target is found. |
| `verify` | `"checks"` | Post-action checks: `"off"`, `"checks"`, or `"full"`. |
| `retryNoEffect` | `false` | Click the runner-up when an ambiguous click provably changed nothing. |
| `focusFallback` | `false` | On very large pages, show the LLM the decision model's shortlist first. |

## Quick start

```typescript
const stagehand = await Stagehand.create({
  browser,
  model: "openai/gpt-5.4-mini",
  experimentalDecisions: { provider: "typesafe", apiKey: process.env.TYPESAFE_API_KEY! },
});

await stagehand.experimentalDecisions.act("Click the sign in button");
const actions = await stagehand.experimentalDecisions.observe("Find the search field");
const product = await stagehand.experimentalDecisions.extract("Extract the product", ProductSchema);
```
