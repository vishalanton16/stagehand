# System One provider feasibility

Checked November 20, 2026 against Stagehand base `93b9d9132`. The first replay should compare Perplexity Decider v1.3 and Flash, TypeSafe Jev 1.14, and Cloudflare Clef Flash through the existing client. Add Luna Decisions through Vercel AI Gateway for native probability outputs and Luna Responses with `reasoning.effort: "none"` as the generative control. If there is room for one new decision model, Microsoft Decision-1.1 uses the same Gateway request shape as Luna Decisions. These are candidates to measure.

## Native decision routes

The [Stagehand adapters](../../packages/extension/services/decisions/providers.ts) send one shared state and named questions. The [client](../../packages/extension/services/decisions/client.ts) handles aliases, question batching, timeouts, retries, and answer validation. Its question types are `choice`, `noul`, and Perplexity-only `locate`. The providers' larger type sets require adapter work.

| Route and model IDs | Documented limits and behavior | Stagehand feasibility |
| --- | --- | --- |
| TypeSafe `POST /v1/systemone`, `jev-1.14.0` | 64k tokens for state plus all questions and 32k for state plus any one question. No separate question-count limit. Up to 255 choices. Questions are evaluated independently against shared state. The opt-in long-context header raises both limits to 262k and has a quality and latency tradeoff. `jev-latest` and `jev-preview` currently point to 1.14.0. [Models](https://docs.typesafe.ai/models), [Choice](https://docs.typesafe.ai/primitives/choice), [State](https://docs.typesafe.ai/concepts/state). | Existing adapter, 8 s per attempt, split at 1,000 questions. Keeps structured JSON instructions and option descriptions. Use the pinned ID for threshold comparisons. |
| Cloudflare Workers AI `POST /ai/run/@cf/cloudflare/{model}`, `clef` and `clef-flash` | 65,536 and 24,576 context tokens respectively. 1–64 questions. Question IDs use letters, digits, underscores, periods and hyphens, up to 100 chars. Long text state can be truncated to fit. Cross-field attention makes packing a variable. The launch announcement's 64K Flash figure predates the hosted limit change. The published choice schema gives no numerical criteria cap. [Clef](https://developers.cloudflare.com/workers-ai/models/clef/), [Clef Flash](https://developers.cloudflare.com/workers-ai/models/clef-flash/), [Request schema](https://developers.cloudflare.com/workers-ai/models/clef/schema-input.json), [Architecture](https://blog.cloudflare.com/clef-decision-models/). | Existing adapter, 15 s per attempt, split at 64. Strings for instructions and descriptions. Use Flash for short packs with headroom. Use full Clef as an optional control and check that gold evidence near the end survives the pack. |
| Perplexity `POST /v1/decisions`, `pplx-decider-v1.3` and `pplx-decider-flash-v1.3` | 255 choices, 32 MiB request, under 256K input tokens for state plus any one question. v1.3 packs bill state once if they fit. Oversized packs split sequentially and rebill state. Sibling questions can still influence each other through shared state. Locate takes string state and caps the pack at 128 questions. It returns exact spans or an empty list. The provider trained Locate up to 8K tokens and evaluated it up to 32K. Keep web grounding off for snapshot replay. [Quickstart and limits](https://docs.perplexity.ai/docs/decisions/quickstart), [API schema](https://docs.perplexity.ai/api-reference/decisions-post). | Existing adapter, 15 s per attempt, split at 128 across all question types. The client verifies Locate offsets against Unicode code points in the original state. Use versioned IDs. The API echoes the requested ID. A retired ID can serve a replacement model. |
| OpenAI `POST /v1/decisions`, `gpt-6-luna`. Vercel AI Gateway equivalent `openai/gpt-6-luna-decisions`. | Direct API is generally available. It accepts 1–400 questions, 2–255 unique values per choice, and 2–10 levels per score. `input_json` supports 32 container levels, 10,000 values and 256 KiB of compact UTF-8 JSON. Individual questions can return refusals. Predicate, choice and score return typed judgments. Existing tool calls and outputs can be supplied as evidence. [OpenAI guide](https://developers.openai.com/api/docs/guides/decisions), [API schema](https://developers.openai.com/api/reference/resources/decisions/methods/create), [Gateway route](https://vercel.com/changelog/openai-decisions-api-now-available-on-ai-gateway). | New encoder and decoder. Map `noul` to `predicate` and convert criteria to ordered `{value, description}` items. Normalize the answer array by question name, preserve the probability distribution, and handle refusals explicitly. Treat direct and Gateway limits as separate until tested. |

The Gateway [model endpoint](https://ai-gateway.vercel.sh/v1/models) listed Luna Decisions, Microsoft `microsoft/decision-1.1` (32,768-token context), and `google/gemini-decision-1` (262K) as evaluation models. It also listed Jev, both Perplexity v1.3 variants, Laya, and Liquid d1. Gateway routes are separate measurements, even when the same weights are available direct. Parallel `parallel/parallel-decisions-fast` retrieves live web evidence, which changes the input to the decision and makes it a poor fit for frozen replay. [Microsoft model](https://vercel.com/ai-gateway/models/microsoft/decision-1.1), [Gemini model](https://vercel.com/ai-gateway/models/google/gemini-decision-1), [Parallel route](https://vercel.com/changelog/parallel-decisions-now-available-on-ai-gateway-for-free).

Clairic is a separate extraction arm. Workers AI `@cf/cloudflare/clairic` is preview and takes `fields` with enum, object, list and scalar types. The field spec rejects unknown keys and the documented prompt limit is 65,273 input tokens. Text fields can require separate passes that rebill the state. Score exact source spans, typed values and absence independently. A null answer can still carry a guess and span. For printed-value tasks, verify scope, boundaries and value against the original source. [Model and schemas](https://developers.cloudflare.com/workers-ai/models/clairic/), [Extraction model guide](https://developers.cloudflare.com/workers-ai/concepts/extraction-models/).

## Generative controls and tool calling

| Route | Structured output, reasoning and tools |
| --- | --- |
| Luna Responses, direct `gpt-6-luna` or Gateway `openai/gpt-6-luna` | Use `text.format` with `strict: true` for the schema arm. OpenAI requires an object root, all fields required, and `additionalProperties: false` on each object. Its subset allows up to 5,000 object properties, 10 levels, 1,000 enum entries across the schema, and 120,000 total characters across names and enum/const strings. A single string enum with more than 250 values has a 15,000-character budget. Handle refusals and incomplete responses. Luna supports `none` through `max` reasoning effort. Responses supports function calling with reasoning. Chat Completions requires `none` for Luna function calling. [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [Luna model](https://developers.openai.com/api/docs/models/gpt-6-luna), [Function calling](https://developers.openai.com/api/docs/guides/function-calling). |
| Gemini `gemini-3.5-flash-lite`, or Gateway `google/gemini-3.5-flash-lite` | Optional generative challenger. Use `minimal` thinking, the documented default. Gemini's JSON Schema subset supports enums and nested objects. Large or deeply nested grammars may return 400, and constraints such as `uniqueItems` and `maxLength` are ignored. Function declarations can constrain native calls. Test the exact endpoint and tool mode before combining tools and response schemas. [Structured output](https://ai.google.dev/gemini-api/docs/structured-output), [Thinking](https://ai.google.dev/gemini-api/docs/thinking), [Function calling](https://ai.google.dev/gemini-api/docs/function-calling), [Model ID](https://ai.google.dev/gemini-api/docs/pricing#gemini-3-5-flash-lite). |
| Groq Chat Completions `openai/gpt-oss-20b` | Optional throughput control. `low` is the lowest supported reasoning effort. Strict JSON Schema mode uses constrained decoding with enum support, required fields and closed objects. Groq's docs disallow streaming and tools in that mode, so evaluate native tool calls separately. Use a schema probe for large enums and deep nesting. The model card's token rate measures throughput. [Model](https://console.groq.com/docs/model/openai/gpt-oss-20b), [Strict mode](https://console.groq.com/docs/structured-outputs), [API reference](https://console.groq.com/docs/api-reference). |

For native decisions, the allowed labels come from the question. Code still owns tool dispatch, stale-target checks and fallback. For generative controls, use a compact enum of candidate IDs or one forced strict function with that enum. Validate candidate membership, operation/target compatibility, and arguments in both cases. A model-generated confidence field has no established relationship to native scores. Even across native providers, a fixed cutoff mixes confidence definitions and calibration. Record choice mass and confidence separately and compare wrong-accept rates at matched coverage.

## What a shared replay can answer

The local history under `vendor-repos/experimental-decisions/packages/sdk-ts/scripts/system-one/docs/` contains useful priors. `ACT_RESULTS.md` reports 27/27 passes for Flash plus Luna fallback and for the paired Luna Responses control. At the same 0.7 gate on development snapshots, correct positive accepts were Flash 18/20, Jev 16/20 and Clef Flash 1/20. That gate result confounds calibration with model quality. `DECISION_PRIMITIVES.md` gives prior six-route group selection and scalar probes, including Luna Decisions through Gateway and Clairic. It used previously seen snapshots. Keep these results as development evidence. The older `JevRouter` code also records an OpenRouter alpha route, which adds a gateway and is outside the initial comparison.

Use the same frozen, labeled snapshots and candidate IDs across arms. Hold snapshot text, candidate order, descriptions, instructions and question packs fixed except for wire encoding. First measure candidate recall. Score single-target accuracy and wrong accepts, complete observe sets, and extraction exact match with source evidence. Include missing and ambiguous targets, competing records, repeated or Unicode spans, and oversized packs. On a small diagnostic subset, reverse candidate order, compare packed with separate questions, and probe enum count, depth and size independently. Keep per-route thresholds fixed on held-out scoring. One fixture can find a format or grounding regression. A shared corpus with repeated, interleaved calls is needed for coverage and p95.

Measure elapsed time to the full validated answer and, for streaming generative calls, time to first token separately. Report p50/p95 with sample counts, failures, 429s, retries, provider and model IDs, calls per task, tokens and request bytes. Record queue, prefill and decode time when exposed. Estimate cost from billed input, output, and cache usage for each route. Also report time and success with the same ordinary Luna fallback. Stagehand's native client retries 429 and 529 and opens a circuit breaker after repeated failures or an auth rejection. Log those outcomes separately. Gateway failover handles request failures where supported. Stagehand fallback also handles uncertainty, invalid answers and changed evidence. Disable optional failover during comparisons or record which route served each call. Frozen replay cannot measure actual click outcomes, live DOM changes or navigation time. [Gateway fallback configuration](https://vercel.com/docs/ai-gateway/models-and-providers/model-fallbacks), [Groq timing metadata](https://console.groq.com/docs/responses-api#detailed-usage-metrics).

Measure first calls and observed warm hits independently. Decider bills state once within a fitting request. Jev and Clef also share state across questions. Treat cross-request cache behavior on those direct routes as unknown. Direct Luna Decisions supports shared-input prefix caching from 1,024 tokens, with read/write counters in usage. Verify whether Gateway forwards the counters and cache controls. Gemini and Groq provide cache-hit usage. Stagehand's result cache and Cloudflare AI Gateway's response cache can bypass inference, so exclude their hits from provider inference latency. Record missing cache metrics as unknown. [Luna Decisions caching](https://developers.openai.com/api/docs/guides/decisions#reuse-shared-input-with-prompt-caching), [Gemini caching](https://ai.google.dev/gemini-api/docs/caching), [Groq caching](https://console.groq.com/docs/prompt-caching), [Cloudflare response caching](https://developers.cloudflare.com/ai-gateway/features/caching/).

## Live availability

One bounded synthetic three-option choice through the Stagehand client returned the expected validated choice for Jev 1.14, Clef, Clef Flash, and both Perplexity v1.3 variants. A separate synthetic check on Gateway `/v1/decisions` returned HTTP 200 and the expected named choice for Luna Decisions, Microsoft Decision-1.1, Gemini Decision 1, and Parallel Decisions Fast. Only the synthetic input was sent. The direct OpenAI route, Clairic and the generative controls were verified through documentation or catalog metadata. These checks establish basic reachability and wire shape for the tested accounts and inputs.
